Excel Import Guide

Complete instructions for bulk uploading questions to NGI Study Zone.

Important: Always use the .xlsx format. Ensure headers match the sample file exactly (case-insensitive).

Supported Question Types

1. MCQ Single (MCQ_SINGLE)

Standard multiple-choice question with one correct answer.

ColumnValue Example
QuestionWhat is the capital of France?
TypeMCQ_SINGLE
Option A-DParis, London, Berlin, Madrid
Correct AnswerA
2. MCQ Multiple (MCQ_MULTIPLE)

Multiple-choice question where more than one answer can be correct.

ColumnValue Example
TypeMCQ_MULTIPLE
Correct AnswerA, C (Comma separated labels)
3. True / False (TRUE_FALSE)

Simple Boolean questions.

ColumnValue Example
TypeTRUE_FALSE
Correct AnswerTrue (or A for True, B for False)
4. Match the Following (MATCH_THE_FOLLOWING)

Connecting items from two columns.

ColumnValue Example
Option A-DLeft side items (e.g. "Mouse", "Monitor")
MatchPair A-DRight side items (e.g. "Input", "Output")
Correct AnswerA-1, B-2, C-3, D-4
5. Assertion & Reason (ASSERTION_REASON)

Classic competitive exam format.

ColumnValue Example
AssertionPlants are green.
ReasonThey contain chlorophyll.
Correct AnswerA (Both true, R is correct explanation)
6. Numeric (NUMERIC)

Questions requiring a specific number as an answer.

ColumnValue Example
NumericAnswer42.5
7. Typing / Descriptive (TYPING)

For typing tests or long-form answers.

ColumnValue Example
ShortAnswerPaste the full passage or target text here.

Global Fields

  • Marks: Default is 1.
  • Negative Marks: Use positive values (e.g., 0.25).
  • Difficulty: EASY, MEDIUM, or HARD.
  • Explanation: Text shown to students after the test.
